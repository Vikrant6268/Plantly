# Plantly

Plantly is a plant issue analysis application built with **Streamlit** and **Python**. Users can upload an image of an affected plant, and the application uses the **Gemini API** to analyze the image.

The AI provides:

- The probable issue affecting the plant
- Possible solutions for the issue
- Reasons why the issue may be happening

The application also uses **Twilio** to send the plant analysis result to the user’s WhatsApp number.

## Features

- Upload an image of an affected plant
- Analyze plant images using the Gemini API
- Identify probable plant issues
- Suggest possible solutions
- Explain possible reasons behind the plant issue
- Send plant analysis results to a WhatsApp number using Twilio
- User interface built with Streamlit
- Python-based application using `app.py`

## Technologies Used

- Python
- Streamlit
- Gemini API
- Twilio WhatsApp API

## Installation

### 1. Clone the repository

```bash
git clone [https://github.com/your-username/plantly.git](https://github.com/your-username/plantly.git)
cd plantly
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Add your credentials

Replace the credentials in the project with your own credentials before running the application.

You need to replace:

- Gemini API key
- Twilio Account SID
- Twilio Auth Token
- Twilio WhatsApp number
- User WhatsApp number, if it is set directly in the code

Example environment variables:

```env
GEMINI_API_KEY=your_gemini_api_key
TWILIO_ACCOUNT_SID=your_twilio_account_sid
TWILIO_AUTH_TOKEN=your_twilio_auth_token
TWILIO_WHATSAPP_NUMBER=your_twilio_whatsapp_number
```

Do not share your API keys, Twilio credentials, or `.env` file publicly.

## Run the Application

Run the Streamlit application using:

```bash
streamlit run app.py
```

After running the command, Streamlit will provide a local URL in the terminal. Open that URL in your browser.

## How It Works

1. Open the application in your browser.
2. Upload an image of an affected plant.
3. The image is sent to the Gemini API for analysis.
4. Gemini analyzes the image and provides:
   - The probable plant issue
   - Possible reasons for the issue
   - Suggested solutions
5. The analysis result can be sent to the user’s WhatsApp number using Twilio.

## Important Notes

- Replace all API keys and Twilio credentials with your own credentials.
- Make sure your Twilio WhatsApp configuration is active before sending messages.
- The plant analysis is generated by AI and provides probable results based on the uploaded image.
- Do not upload or commit `.env` files containing private credentials to GitHub.
